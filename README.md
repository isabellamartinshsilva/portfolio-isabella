# Portfólio de Isabella Martins

Currículo e portfólio feito com Next.js (App Router) e CSS puro.
A lista de repositórios e as estatísticas vêm da API pública do GitHub.

## Páginas

- `/` Home
- `/sobre` Sobre, com as tecnologias usadas no site
- `/experiencia-academica`
- `/experiencia-profissional`
- `/projetos`

## Como rodar

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Como editar o conteúdo

Todos os textos estão em `lib/data.js`.

## Deploy

Importe o repositório na Vercel (vercel.com/new). Não precisa de configuração extra.
